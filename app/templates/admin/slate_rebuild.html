  1. Every existing pick for this week is copied into an archive table, then removed from the live table. It is never permanently destroyed; it can still be looked up by hand afterward.
  2. The slate is rebuilt from current data, the same closest-games selection an ordinary build uses.
  3. The week goes back to draft. It is not published automatically. You review the new slate and publish it yourself when you are ready.
  4. The moment you publish it, every member gets an email that the slate changed, their previous picks were cleared, and they need to submit again by the new lock time. If mail fails for anyone, you will see a copyable message to send by hand.

A narrower alternative: if only one game needs to change, use "Amend this game" on the slate editor instead. It voids only the picks on that one game and leaves the rest of the slate and every other player's pick alone.
